# SCLLAB annotation tool

憲法法庭卷內文書的 OCR 校對工具。左邊是原始頁面圖片，右邊是 OCR 出來的文字，請對照圖片把右邊的文字改成跟圖片一致。

## 一、事前準備（只需做一次）

1. 安裝 Python 3.8 以上版本：<https://www.python.org/downloads/>
   - **Windows**：安裝時務必勾選「Add python.exe to PATH」。
   - **Mac**：通常已經內建。若之後跳出「要安裝開發者工具」的視窗，按「安裝」即可。
   - **Linux**：通常已經內建。
2. 下載本工具：在 GitHub 頁面按綠色的 **Code → Download ZIP**，下載後解壓縮。會用 git 的人也可以直接 `git clone`。

## 二、啟動

依你的系統，雙擊資料夾裡對應的檔案：

| 系統 | 檔案 |
|---|---|
| Windows | `start.bat` |
| Mac | `start.command`（第一次若出現「無法驗證開發者」，改成「按右鍵 → 打開 → 打開」） |
| Linux | `start.sh`（或在終端機執行 `./start.sh`） |

- 第一次啟動會自動安裝需要的套件，要等一兩分鐘，且需要網路。之後啟動就會很快。
- 啟動後瀏覽器會自動打開校對頁面。如果沒有自動打開，請看黑色視窗裡「開啟瀏覽器: http://127.0.0.1:....」那一行，把網址貼到瀏覽器。
- 校對時不要關掉那個黑色視窗，關掉工具就會停止。

## 三、操作

| 動作 | 方式 |
|---|---|
| 儲存 | 「儲存」按鈕，或 Ctrl+S（Mac 為 Cmd+S） |
| 換頁 | 上一頁／下一頁按鈕、Alt+← / Alt+→、左側清單、輸入頁碼跳頁。換頁時會自動儲存目前這頁 |
| 圖片放大縮小 | 圖片上方的 − / + 按鈕，或 Ctrl+滑鼠滾輪 |
| 文字字級 | A− / A+ 按鈕 |
| 直式／橫式 | 「直」按鈕 |

⚠️ 儲存會直接覆寫 `txt/` 資料夾裡的檔案，沒有備份。

## 四、校對原則

- 以圖片為準，逐字照抄，不要修正原文本身的錯字，也不要改寫。
- 真的看不清楚的地方，寫 `[無法辨識]`，不要用猜的。
- 只校對分配給你的頁面。
- 不要改檔名，不要新增或刪除檔案。

## 五、完成後交回

- **不會用 git**：把 `txt/` 資料夾壓縮成 zip 傳回即可（`img/` 不用傳）。
- **會用 git**：fork 本 repo，開一個 branch 修改後發 Pull Request。

## 檔案說明

- `txt/<文件名>_page-NNNN.txt`：每頁的 OCR 文字（要校對的對象）
- `img/<文件名>_page-NNNN.jpg`：對應的頁面圖片
- `tool.py`：校對工具本體（Flask 網頁程式）
- `start.bat` / `start.command` / `start.sh`：各系統的啟動檔，第一次執行時會在資料夾內建立 `.venv` 並安裝 `requirements.txt`
